# VCO home page prototype

A single-page prototype of the VCO Registered Valuers home page, used for the brand presentation.

- One self-contained file: `index.html`. No build step, no images, no frameworks.
- Fonts: Jost and IBM Plex Mono from Google Fonts.
- The yellow dot fields are drawn in the browser from a seeded generator, so they render the same on every visit.
- Motion is off for visitors who set "reduce motion"; pointer effects only run with a mouse.

To view locally, open `index.html` in a browser. To host, turn on GitHub Pages for the `main` branch (root folder).

Contact details are placeholders.
